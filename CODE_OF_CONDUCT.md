# Code of Conduct

## Our standard

Contributors and maintainers of AutoTotem are expected to communicate respectfully and constructively.

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, deliberate disruption, doxxing, publishing private information, and intentionally malicious behavior.

## Project discussions

Keep technical discussions focused on the project. Disagreement about an implementation is welcome when it remains professional and evidence-based.

## Reporting problems

For conduct concerns, contact the project maintainer through the repository's available GitHub contact or issue/reporting channel. Do not publish private or sensitive information in a public issue.

Maintainers may remove content, close discussions, or restrict participation when necessary to keep the project usable and safe.

This code of conduct applies to repository issues, pull requests, discussions, documentation contributions and other project spaces controlled by the maintainers.
